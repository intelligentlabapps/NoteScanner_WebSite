NoteScanner — Netlify-ready static website

Deploy:
1. Open Netlify.
2. Drag this extracted folder into Netlify Deploys (or upload the ZIP if your Netlify flow supports it).
3. index.html is at the project root; no build command is required.

This build includes:
- The existing animated NoteScanner hero.
- A one-time smooth hero-to-features auto-scroll invitation (cancelled when the visitor starts interacting).
- An automatically looping feature slideshow made exclusively from real NoteScanner interface screenshots.
- High-resolution 2x screenshot masters for crisp high-DPI browser rendering.
- A real-interface collage built from NoteScanner screenshots only.
- The NoteScanner competitor comparison table.
- Responsive Bootstrap-based styling.
